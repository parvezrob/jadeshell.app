Features · one desktop, one family

A redrawn Shell, on the GNOME you keep.

Everything below lives in GNOME Shell itself: no new session, no replacement window manager. Turn any part off in the Jade Shell app.

Theme picker

22 themes, dark and light. One click re-colors all of it.

Click the palette in the top bar or press Super+Ctrl+Shift+Space. The menu stays open while you try themes, and each one keeps the wallpaper you last gave it.

The dock

Magnification, genie, bounces. At 180 Hz.

  • Icons grow under the pointer, a label names each one, running apps get a dot. Try the real thing above.
  • Windows pour into their icon when minimized; an app bounces until its window is up.
  • Drawn on frosted glass in the theme’s colors, moved by GPU transforms: 0.09 ms of work per frame.
The top bar

A redrawn bar, one icon family.

  • 148 original icons, GNOME’s status icons included, all on the same rhythm.
  • Numbered workspaces replace Activities, as in Omarchy’s Quattro bar. Weather sits by the clock, no Weather app needed.
  • Claude and Codex usage as one icon, with Omarchy’s usage panel as its menu.
Jade MenuSuper+Alt+Space

A keyboard menu for everything: apps, capture, toggles, style, setup, system. Type to search it all.

Clipboard historySuper+Ctrl+V

Text and images, newest first, searchable. Memory only, and never what a password manager marks secret.

Screenshot cardPrint

A card in the corner: Edit, Text (copies the words in it), Pin (keeps it above your windows), Files.

Color pickerSuper+Print

Copies #rrggbb. Capture also has Copy Text from Screen and Read QR Code.

Network panelSuper+Ctrl+W

Signal, ping, DNS. Test Speed on demand, Share Wi-Fi as a QR code a phone joins from.

NotificationsSuper+V

Behind a bell, in a panel of their own, with Do Not Disturb and Clear at the top.

Shortcut sheetSuper+K

Every shortcut on this desktop, Jade’s, GNOME’s and yours, in one searchable sheet.

Frosted glassToggles

Top bar, menus, dialogs and the screenshot card blur what is behind them, tinted by the theme.

Omarchy keymapoptional

Omarchy’s keys on GNOME’s own shortcuts. Every key is saved first; jade keys revert puts them back.

System monitortop bar

CPU, memory, GPU and temperature from /proc and sysfs. Never polls the GPU on battery.

Nothing matches. Try “clipboard” or “keys”.
Undo · nothing is a one-way door

Try it. Your desktop comes back exactly.

Every switch saves what it will change before it changes it. Edits you made to a config since are kept.

kitty — ~
~ › jade theme plan tokyo-night # shows exactly what would change, changes nothing ~ › jade theme set tokyo-night ~ › jade theme undo # puts back what the last switch changed; again walks further back ~ › jade keys revert # every key the Omarchy keymap moved, back where it was ~ › jade restore # extensions, keys, configs: the desktop from before Jade Shell ~ ›
Saved before every switchThe 30 most recent switches are kept, plus the state from before your first.
Checked against SHA256SUMSThe package is verified before anything is installed.
Updates the normal wayThrough dnf, apt or GNOME Software.
Community themes can’t run codeOnly their colors, wallpapers and a preview are kept. Scripts never run.
Install · one line

Paste it, log out, log back in.

Run it as your desktop user. It fetches the latest .rpm or .deb, checks it, installs it with dnf or apt, then sets up Osaka Jade.

kitty — ~
~ › curl -fsSL https://jadeshell.app/install | bash
# jadeshell.app/install is install.sh on GitHub: read it first if you like. # then log out and back in once. The Welcome page opens: # pick a theme, glass, icons, the keymap and your weather city. OS: Fedora Linux 44 or Ubuntu 26.04 Desktop: GNOME 50 Remove: the same line with bash -s -- --uninstall
